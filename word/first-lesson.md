# Microsoft Word darsi 1: Boshlang‘ich tushunchalar

## 1. Microsoft Word nima?

Microsoft Word — matnli hujjatlar yaratish, tahrirlash va formatlash uchun mo‘ljallangan dastur.

## 2. Asosiy imkoniyatlari

- Matn yozish va tahrirlash
- Shrift va o‘lchamni o‘zgartirish
- Jadval yaratish
- Rasmlar joylashtirish
- Sahifa raqamlarini qo‘shish
- Hujjatni PDF shaklida saqlash

## 3. Muhim tugmalar

- Ctrl + C — nusxa olish
- Ctrl + V — joylashtirish
- Ctrl + X — kesib olish
- Ctrl + Z — oxirgi amalni bekor qilish
- Ctrl + S — saqlash
- Ctrl + B — matnni qalin qilish

## 4. Amaliy topshiriq

1. Word dasturini oching.
2. Yangi hujjat yarating.
3. Hujjatga sarlavha yozing.
4. Matnni qalin va rangli qilib ko‘ring.
5. Hujjatni saqlang.

## 5. Xulosa

Microsoft Word talabalar uchun referat, mustaqil ish, ariza va boshqa hujjatlarni tayyorlashda muhim vositadir.
