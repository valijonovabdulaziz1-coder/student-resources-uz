# Student Resources UZ 📚

Welcome to Student Resources UZ!

This is an open-source educational project created to help Uzbek students access useful learning materials and improve their digital skills.

## 🎯 Our Mission

Our mission is to make education more accessible for students in Uzbekistan by providing free and useful educational resources.

## 📖 What You Can Find Here

Economics and business study materials
Microsoft Word tutorials
Microsoft Excel tutorials
Computer and technology guides
Independent study resources
Useful educational websites

## 🌍 Who Is This Project For?

This project is for university students, teachers, beginners, and anyone interested in learning.

## 🤝 How to Contribute

Everyone is welcome to contribute!

You can help by:
Adding useful educational materials
Improving documentation
Correcting mistakes
Translating resources into Uzbek
Sharing useful learning resources

## 📌 Project Status

This project is under active development.
